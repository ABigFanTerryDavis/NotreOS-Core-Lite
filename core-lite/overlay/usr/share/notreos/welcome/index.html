NotreOS · Core Lite 0.0.1

Welcome.

This is the first Core Lite desktop seed. P4DE is starting with a light XFCE session, a NotreOS look, and the everyday tools below already on your live system.

Browse

Epiphany is included for web pages. It can be used when a connection is available.

Files

Thunar is your file manager. The live session keeps changes in memory and is not a disk installer.

Write and view

Mousepad, Ristretto, and File Roller are included for notes, pictures, and archives.

Connect

Open the network icon in the panel to set up Wi-Fi or wired networking.

This live image is built from the Ubuntu 24.04 LTS package base. It is designed to run without installing packages or downloading the desktop after boot.
